Project Overview

The B.R.I.M. (Barangay Resident Information Management) API is a RESTful service built with Laravel 11. It serves as the central orchestration layer for barangay operations, integrating third-party services like Stripe for payments, Traccar for SMS, and Make.com for document automation.

Base URL

https://brim-api.test/api

Response Format

JSON (application/json)

Authentication & Security

Our API implements Laravel Sanctum for token-based authentication. To secure the system against enumeration attacks, we utilize UUIDs as primary keys for all public-facing resources.

HEADER REQUIREMENT:

Authorization: Bearer {your_api_token}

* Tokens can be generated through the User Dashboard under "Developer Settings."
